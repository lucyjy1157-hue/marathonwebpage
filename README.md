# 퍼플페이스

퍼플페이스는 현재 페이스를 아는 러너와 아직 모르는 초보 러너가 각자 다른 방식으로 시작할 수 있는 마라톤 훈련 플래너 웹사이트입니다. 목표 거리, 목표 페이스, 목표 날짜를 입력하면 긴 표 대신 핵심 단계별 훈련 흐름을 보여주고, 훈련 후 기록 이미지를 업로드하면 체감도와 완료율을 바탕으로 다음 훈련 조정 코칭을 제공합니다.

## 주요 기능

- 현재 페이스를 아는 사용자는 페이스를 직접 입력해 바로 계획을 생성합니다.
- 현재 페이스를 모르는 사용자는 측정 기록을 입력하거나 임의 시작 수준을 선택할 수 있습니다.
- 목표 거리, 목표 페이스, 목표 날짜, 주간 훈련 횟수를 반영해 훈련 흐름을 생성합니다.
- 초반, 증가, 핵심, 마무리 단계로 압축해 읽기 쉬운 계획을 제공합니다.
- 러닝 기록 이미지를 업로드하고 체감도, 완료율을 선택하면 이후 훈련 조정안을 보여줍니다.
- 보라색 메인 컬러, Pretendard 폰트, 그라디언트 없는 정적 HTML/CSS/JS 구조로 제작했습니다.

## 파일 구조

```text
.
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets
    ├── favicon.png
    ├── hero-runner.png
    ├── meta-image.png
    ├── onboarding-choice.png
    └── upload-coaching.png
```

## 실행 방법

별도 빌드 과정이 없는 정적 웹사이트입니다. `index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 이미지 제작

이미지는 Imagegen 스킬을 사용해 제작했습니다.

- `hero-runner.png`: 메인 히어로 영역 러너 이미지
- `onboarding-choice.png`: 페이스를 아는 사용자와 모르는 사용자의 시작 방식 이미지
- `upload-coaching.png`: 기록 이미지 업로드 및 코칭 섹션 이미지
- `meta-image.png`: Open Graph 및 소셜 공유용 메타 이미지
- `favicon.png`: 브라우저 파비콘 및 앱 아이콘 이미지

## 참고

현재 버전은 프론트엔드 프로토타입입니다. 기록 이미지의 실제 OCR 분석이나 AI 코칭 API 연동은 포함되어 있지 않으며, 업로드 여부와 사용자가 선택한 체감도, 완료율을 기준으로 코칭 문구와 훈련 조정안을 생성합니다.
